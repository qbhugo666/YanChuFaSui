# 项目介绍页

这一页用来让第一次了解言出法随的人，快速看到它为什么被制作、现在能做什么，以及部分真实操作演示。详细功能、安装和开发说明请看仓库首页的 README。

- [在线查看项目介绍页](https://yanchufasui.pages.dev/)
- [查看页面源码](publish-ready/index.html)
- [下载最新正式版](https://github.com/qbhugo666/YanChuFaSui/releases/latest)

`publish-ready/` 保存可直接部署的静态页面和必要素材。网页目前托管在 Cloudflare Pages；这里保存对应的页面文件，不需要购买域名，也不是另一个 App 版本。

## 页面与下载版本

- `project-intro.html` 是本地介绍页原稿，`publish-ready/index.html` 是对应部署入口；两者的下载按钮都指向 v0.59.3 APK。
- 此目录为 v0.59.3 公开发布后的配套页面；须先确认对应 GitHub Release 和 APK 可以公开下载，再部署。
- `index.html` 是保留的早期页面，不是 Cloudflare 当前部署入口；其中下载版本标注同步为当前公开版本。
- 上传包由 `publish-ready/` 的内容生成，入口 `index.html` 必须位于 ZIP 根目录；保留现有分享图片与 Open Graph 标签。
